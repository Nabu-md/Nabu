## Customizing Shortcuts

You can customize keyboard shortcuts in **Settings** → **Keyboard Shortcuts**.

### How to Change a Shortcut

1. Go to **Settings** → **Keyboard Shortcuts**
2. Find the action you want to customize
3. Click the current shortcut
4. Press the new key combination
5. The change is saved automatically

### Shortcut Format

Shortcuts are stored as strings like:
- `Cmd+Shift+Space`
- `Ctrl+Alt+P`
- `Cmd+Shift+Alt+K`

### Platform Conventions

- **macOS**: Uses `Cmd` key for primary shortcuts
- **Windows/Linux**: Uses `Ctrl` key for primary shortcuts
- `Alt` is `Option` on macOS

## Accessibility

### VoiceOver (macOS)

- `Cmd+F5`: Toggle VoiceOver
- `VO+A`: Read all
- `VO+Shift+Down`: Open rotor

### Screen Reader (Windows)

- `Insert+Space`: Toggle screen reader
- Standard Windows accessibility shortcuts apply

## Tips

1. **Conflicts**: If a shortcut is already in use, Nabu will warn you
2. **Reset**: Go to Settings → Advanced → Reset to Defaults to restore original shortcuts
3. **Export**: Shortcuts are included in settings export/import
4. **Platform-specific**: Some shortcuts automatically adapt to your OS

## Troubleshooting

### Shortcut Not Working

1. Check if another app is using the same shortcut
2. Try a different combination
3. Reset to defaults in Settings
4. Restart Nabu

### Resetting Shortcuts

1. Go to **Settings** → **Keyboard Shortcuts**
2. Click **"Reset to Defaults"** at the bottom
3. Confirm

### Export/Import Shortcuts

Shortcuts are saved in your settings. Use **Settings** → **Import & Export** to migrate them between devices.
