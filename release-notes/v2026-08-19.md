## New Features

- 🔗 **Create notes from unresolved wikilinks** — Turn a missing wikilink into a new note beside the source and keep writing without breaking your flow.
- 🤖 **MCP vault lifecycle tools** — Connected AI agents can now open, switch, and manage vaults through dedicated MCP lifecycle tools.
- 📮 **Tracked contribution destinations** — Send feedback and contributions to the right destination so reports reach the project instead of getting lost.

## Improvements

- 📊 **More readable spreadsheet cells** — Cell input stays readable while you edit, instead of disappearing into low-contrast text.
- 📝 **More reliable lists and bullets** — Nested ordered lists keep their indentation and numbering, and bullet markers stay the right size.
- 🔗 **Better paste and link handling** — Pasting a URL keeps your selected text, and linked inline code and rich-pasted code survive the editor.
- 🎨 **Live code-block language picker** — Language selection on code blocks updates immediately instead of sticking on a stale control.
- 🪟 **Dialogs keep Escape** — Open dialogs now handle Escape themselves instead of letting it leak through to the rest of the app.
- 📴 **Offline-ready fonts** — Fonts ship with the app so the first launch still looks right without a network.
- 📋 **Steadier blockquotes** — Adjacent quote paragraphs join correctly and keep their spacing.
- 🧭 **Note list retargeting restored** — Changing the note-list target updates the list you are looking at.
- 💻 **Windows OpenCode path refresh** — OpenCode is rediscovered on Windows when its install path changes.

## Stability and Fixes

- Recovered from unwritable app config so Nabu can start again instead of getting stuck.
- Contained native spreadsheet pointer failures and stopped selection flicker while editing sheets.
- Preserved late Korean and Chinese IME commits, including inside nested bullets.
- Hardened blockquote parsing and serialization so long quotes stay intact.
- Surfaced Pi agent output failures and skipped unreliable OpenCode desktop discovery.
- Kept the editor from dropping keystrokes, list formatting, or rich-paste typing during recovery.
